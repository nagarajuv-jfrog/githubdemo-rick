In AppTrust, applications are business-aware entities that serve as a definitive, centralized, system of record for all software assets throughout their lifecycle. AppTrust applications integrate crucial business context such as business criticality, maturity level, and explicit ownership directly into the software development lifecycle (SDLC). Software packages and builds are bound to their owning application, which establishes explicit and auditable links between them.

This section describes how to create and manage applications in AppTrust, including:

* Create an Application
* Edit an Application
* View Application Details
* Delete an Application
