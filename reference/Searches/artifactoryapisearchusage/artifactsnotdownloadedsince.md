  Returns all artifacts not downloaded since the specified Java epoch in
  milliseconds. Optionally include only artifacts created before the specified
  `createdBefore` date, otherwise only artifacts created before `notUsedSince`
  are returned. Can limit search to specific repositories (local or caches).
